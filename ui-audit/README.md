# FluBird Hospital Management System — UI & Security Audit Package

## Overview
This directory contains the complete, automated UI & Security Audit package for **FluBird HMS MedCore Enterprise** (`apps/hms-client`).

## Audit Artifacts Index

| Filename | Description |
| :--- | :--- |
| **`ui-audit.pdf`** | Comprehensive full-size visual audit document with one full-page screenshot per route, metadata header, and status badge. |
| **`ui-audit-report.md`** | Authoritative Master Audit Report covering executive summary, findings across all domains, and prioritized issues. |
| **`interaction-test-report.md`** | Detailed verification log of authentication, multi-role workspaces, and interactive modal dialogs. |
| **`security-test-report.md`** | Non-destructive security evaluation covering RBAC enforcement, tenant isolation, and Zero-PHI boundary verification. |
| **`route-manifest.json`** | Machine-readable manifest of all 53 discovered and tested routes with DOM metadata and status. |
| **`browser-console-errors.json`** | Detailed log of all browser console events captured during live crawling. |
| **`failed-network-requests.json`** | Network trace log capturing all non-2xx HTTP responses during navigation. |
| **`accessibility-report.json`** | Automated WCAG 2.1 AA accessibility audit results generated by axe-core. |
| **`screenshots/`** | Full-resolution desktop screenshots (1920x1080) for all 53 routes and interactive modals. |
| **`mobile-screenshots/`** | Mobile viewport screenshots (390x844) for primary clinical and administrative workflows. |

## Execution Methodology
- **Application URL**: `http://localhost:3000`
- **API URL**: `http://localhost:3001/api/v1`
- **Desktop Viewport**: 1920 x 1080
- **Mobile Viewport**: 390 x 844
- **Engine**: Puppeteer Core driving local Chrome binary
- **Testing Principle**: Read-only observational audit. Zero application source code modifications.
